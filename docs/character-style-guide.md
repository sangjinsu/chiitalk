# 캐릭터 말투와 근거

기본 모델은 Haiku 5.5, 이번 릴리스 source는 `2026-10-18-v8-subtitle-voices`다. 첫 자막 기준 v7은 실제 32개에서 두 발화행위 오류를 확인해 배포를 보류했으며, 보정한 v8의 같은 32개 실제 재검수를 완료했다. 검수 당시 공개 기준점은 10/17 Git `3dcaf8bb84b7a7dcba73529a05823b800e058d3b`로 배포한 v5다. 이번 공개 배포의 Git SHA·Vercel `READY`·도메인 연결은 별도 릴리스 증거로 확인한다. 이전 판정과 원 208개 HOLD는 보존한다. [적용 이력](evaluation-v3.md#haiku-기본-모델-적용과-모몽가-추가-검증)과 [v8 보정·결과](evaluation-v3.md#v8의-발화행위와-발성-보정)를 구분하며, 제품 예시는 공식 대사나 정답이 아니다.

한국어 애니메이션 더빙에 더해 사용자가 요청한 **일본 애니메이션의 한국어 번역 자막**을 참고한다. 기존 공식 업로드·성우 자료와 새 팬 비교 자막의 범위는 [한국어 말투 연구](korean-dub-research.md)에 기록했다. 제목·설명·player 길이, 화면의 번역 자막, 실제 음성·화자는 서로 다른 근거다. 새 조사는 화면 관찰이며 직접 청취·공식 한국어 대본 검수를 완료한 것은 아니다.

v7에서 정한 공통 방향은 v8에서도 **핵심 감정·의도를 캐릭터가 자기 방식으로 말하듯 재구성**하는 것이다. 긴 입력도 배경·이유·중복·세부 시점을 덜어내고 한마디·감탄·끊긴 말·호흡으로 압축할 수 있다. 말할 수 있는 캐릭터에도 완결 문장의 최소 개수를 강제하지 않는다. 구체 부탁·정보 전달에서는 핵심 대상·행위·방향을 짧게 남기며, 남긴 사실·거절·소유·반환 방향을 뒤집지 않는다. 문맥에 맞는 수사 질문·비유·허세와 새 실제 사건·구체 행동·약속·요구를 분리한다. 원문 그대로나 어미만 교체한 결과는 의미 오류와 별도로 재표현이 부족한지 평가한다.

발성형은 의성어·짧은 감탄 **1–4개, 구두점 포함 48 Unicode code points, 동일 문자 연속 최대 4회** 안에서 감정의 높낮이·끊김·쉼을 표현한다. 뜻을 설명하는 단어·문장·이름, 뜻단어의 음절 쪼개기, 행동 지문·설명 wrapper는 넣지 않는다. 이 상한은 제품 정책이며 공식 더빙의 절대 규칙이 아니다. 정보가 압축되는 발성에서 물건명·시점을 단어로 완전히 재현하도록 요구하지 않고, 불명확한 소리를 동의·거절로 단정하지 않는다. 후루혼야의 작은 반응은 한국어 본인 발화 근거가 없는 잠정 정책이다.

v8은 첫 실제 v7에서 발견한 오류를 좁게 보정한다. 부탁을 상대의 수락 약속으로, 일어난 일을 전하는 진술을 확인 질문으로 바꾸지 않도록 같은 화자의 발화행위를 고정한다. 하치와레의 반환 요청과 말 중심 세 캐릭터의 중립 진술을 직접 작성한 대조 예시로 보강했다. 발성 중심 네 캐릭터는 정해 둔 짧은 재료를 조합해 뜻단어·원문 단어 조각의 잔존을 줄이도록 한다. 발성 재료는 **잠정 제품 해석**이며 공식 한국어 자막 철자나 캐릭터의 발화 불가능을 입증하지 않는다.

같은 32개 재검수는 비맹검 AI 기준 pass 29·weak 3·major 0이었다. 하치와레의 두 의도 반전과 발성형 뜻단어·단어 조각 문제는 이 표본에서 재발하지 않았다. 남은 치이카와 발성 재료 변형 2건과 쿠리만쥬 음표 1건은 보완점이다. 모몽가의 수사적 자기 칭찬을 허용하더라도 실제 말버릇의 빈도를 확인한 것은 아니다. 같은 결과를 보고 보정한 표본이므로 독립 holdout·사람 평가·8명 전체의 원작 정확도로 확대하지 않는다.

하치와레의 자기 생각을 상담 답변으로 바꾸지 않는다. 모몽가는 원래 바람이 있을 때 짧고 당당한 요구·늘임을 사용할 수 있지만 슬픔·감사·중립에 새 강요나 약속을 자동으로 붙이지 않는다. 랏코의 차분한 일상 어미는 제품 해석이고 기존 166화 AI 후보는 의문·놀람의 제한된 보조 자료다. 원 v4 비교와 v5 추가 30개는 옛 source·rubric의 기록으로 보존하며 새 v7 품질이나 정확 더빙 일치로 확대하지 않는다. v5의 타 7캐릭터 payload 동등성도 공통 규칙이 바뀌는 v7에는 재사용하지 않는다.

## 이전 소개·원작·더빙 조사 기록

초기 확인일: 2026-10-10, 공식 원작·한국어 후보 자료 추가 검수: 2026-10-11. 아래는 당시 소개·인터뷰·일본어 원작·script UI의 관찰 기록이다. 당시 기본 64예시는 새로 쓴 한국어 재해석이며 공식 대사 인용이 아니다. 한국어 번역 본문과 더빙 음성을 직접 대조하지 않았으므로 한국어 표기·말끝·소리의 길이가 공식 더빙과 같다고 주장하지 않는다. 새 10/18 자막 관찰은 위 절로 분리한다.

근거 등급은 **A: 공식 소개에 명시된 성격/발성**, **B: 공식 인터뷰에 명시된 연기 특성**, **C: 제품을 위한 잠정 한국어 표현**이다. A/B 근거가 있어도 한국어 어미와 예시 자체는 C다.

추가 원작 관찰은 **R: 출판사의 공식 일본어 원작 미리보기에서 직접 확인한 발화**로 구분한다. R도 관찰한 장면만 뒷받침하며 한국어 더빙 표현이나 작품 전체의 반복 빈도를 증명하지 않는다.

**D: 출판사의 comic-cut 파생상품 sample에서 직접 관찰한 발화**는 R과 구분한다. 원래 책 쪽수와 앞뒤 문맥이 확인되지 않아 책 본문의 직접 검수나 발화 빈도 근거로 확대하지 않는다.

후루혼야의 성격 근거는 인터뷰로 보강했고 출판사 파생상품의 comic-cut에서 짧은 웃음을 추가 관찰했다. 전체 발화 패턴의 근거는 여전히 부족하다. 짧은 웃음·반응을 허용하고 장문을 억제하는 비언어 스타일은 잠정 제품 결정이며 언제나 비언어로만 말하거나 완전히 무음이라는 사실 주장이 아니다. 한국어 더빙에서 발화를 확인하면 이 결정을 먼저 재검토한다.

변환할 글은 지시가 아닌 데이터로 취급하고 결과 대사만 출력한다. 원문에 없는 실제 사실·조언·지문을 넣지 않는다. 발화 유형과 무관하게 핵심 감정·의도를 우선하고 필요한 배경 생략을 허용한다. 비언어 표현은 구체 정보가 줄어들 수 있으며 이를 단순 누락률로 평가하지 않는다. 화면의 선택 캐릭터 안내에도 정보 축약 가능성을 알린다.

`characters.ts`는 공개 메타데이터다. `character-styles.ts`는 서버와 CLI 평가에서만 import하며 프롬프트와 예시는 클라이언트에 전달하지 않는다. 기본 예시는 캐릭터별 기쁨·속상함·두려움·요청·자랑·감사·피로·거절을 다룬다. 모몽가는 별도 경계 예시로 요구·다짐이 없는 슬픔/성취, 감사·중립·허용·지시를 데이터로 변환하는 경우를 구분한다. 발화 의도에 맞는 예시와 대비 예시를 요청당 최대 3개 선택한다. 선택기는 완전한 의미 분석기가 아니며 입력 길이만으로 소리 모드를 결정하지 않는다. 실제 감정 유지와 개성은 모델 출력으로 확인한다. 추가 감정 모델이나 RAG는 사용하지 않는다.

첫 3개 후보를 읽은 적용 범위는 제한적이다. 시사 123화는 상대에게 정중히 부탁하는 `~주세요`의 방향을 새 요청 예시에 참고할 수 있지만 상시 애원·허락 요청을 만들지 않는다. 하치와레 25화는 부드러운 자기 독백과 졸림 뒤 놀람의 태도 후보이며, 보고된 어미는 cue와 대응하지 않아 고정하지 않는다. 치이카와 1화는 짧은 소리·작은 웃음의 후보로만 다루고 뜻단어·동의나 거절의 의미를 확정하지 않는다. 다른 감정으로 옮긴 새 직접 작성 표현은 제품 해석으로 표시한다. 세 후보 모두 사람 청취 0·정확 전사 및 시각 미확정이다.

v5에서 쿠리만쥬 35화는 만족 태도만 좁게 참고한다. 모델의 삼킴효과 표기를 유성 숨소리나 한국어 뜻단어로 바꾸지 않으며, 예시의 호흡은 기존 일본어 자료와 제품 해석에 연결한다. 모몽가 118화와 성우 본인 샘플은 같은 감싸기 요구 장면일 수 있다. 요구 입력에서 당당하게 같은 요구를 짧게 반복하는 방향을 참고하되, 보고된 두 말끝을 고정 어미로 만들거나 감사·피로·거절에 강요를 덧붙이지 않는다. 시사 124화는 123화와 정중 요청 방향을 보강하며 새 음식명·위로·상시 호소를 추가하지 않는다.

우사기 9·104화, 랏코 54·103화, 영화 후루혼야 후보는 새 한국어 말투 근거로 채택하지 않았다. 우사기 66화의 높은 톤 환호 후보는 기쁨 맥락에만 좁게 참고한다. 두 cue의 철자를 기존 소리의 더빙 정답으로 정규화하지 않으며 다른 감정의 발성은 기존 제품 해석이다. 랏코 166화는 target의 초기 근거가 제목/script 단서뿐이므로 본인 화자 미확인을 유지한다. 입력에 의문·놀람이 있을 때 짧은 반응 방향만 조건부 참고하며 호칭·정확 반응어·새 어미는 도입하지 않는다. 랏코의 공통 8 예시 전체는 담백한 제품 각색이다. 27화 형식 실패도 새 말투 근거로 사용하지 않는다.
