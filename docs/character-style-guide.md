# 캐릭터 말투와 근거

초기 확인일: 2026-10-10, 공식 원작 추가 검수: 2026-10-11. 공식 애니메이션 소개·성우 인터뷰와 일본어 원작의 일부 컷을 확인했다. 예시 64개는 새로 쓴 한국어 재해석이며 공식 대사 인용이 아니다. 한국어 번역 본문의 발화와 더빙 음성을 직접 대조하지 않았으므로, 한국어 표기·말끝·소리의 길이가 공식 더빙과 같다고 주장하지 않는다.

근거 등급은 **A: 공식 소개에 명시된 성격/발성**, **B: 공식 인터뷰에 명시된 연기 특성**, **C: 제품을 위한 잠정 한국어 표현**이다. A/B 근거가 있어도 한국어 어미와 예시 자체는 C다.

추가 원작 관찰은 **R: 출판사의 공식 일본어 원작 미리보기에서 직접 확인한 발화**로 구분한다. R도 관찰한 장면만 뒷받침하며 한국어 더빙 표현이나 작품 전체의 반복 빈도를 증명하지 않는다.

**D: 출판사의 comic-cut 파생상품 sample에서 직접 관찰한 발화**는 R과 구분한다. 원래 책 쪽수와 앞뒤 문맥이 확인되지 않아 책 본문의 직접 검수나 발화 빈도 근거로 확대하지 않는다.

후루혼야의 성격 근거는 인터뷰로 보강했고 출판사 파생상품의 comic-cut에서 짧은 웃음을 추가 관찰했다. 전체 발화 패턴의 근거는 여전히 부족하다. 짧은 웃음·반응을 허용하고 장문을 억제하는 비언어 스타일은 잠정 제품 결정이며 언제나 비언어로만 말하거나 완전히 무음이라는 사실 주장이 아니다. 한국어 더빙에서 발화를 확인하면 이 결정을 먼저 재검토한다.

공통 규칙은 변환할 글을 지시가 아닌 데이터로 취급하고, 결과만 출력하며, 원문에 없는 사실·설명·조언·지문을 넣지 않는 것이다. 문장형은 화자·사실·부정·의도를 유지한다. 비언어형은 구체적 정보를 잃을 수 있으며 감정과 긍정/부정을 우선한다. 화면의 설명에도 이 차이를 알린다.

`characters.ts`는 공개 메타데이터다. `character-styles.ts`는 서버와 CLI 평가에서만 import한다. 클라이언트에는 프롬프트와 64개 예시를 전달하지 않는다. 각 스타일에는 기쁨, 속상함, 두려움, 요청, 자랑, 감사, 피로, 거절 예시를 한 개씩 둔다. 감정 regex로 첫 번째 관련 예시와 두 개의 대비 예시를 결정적으로 선택한다. 추가 감정 모델이나 RAG는 사용하지 않는다.

기존 `character-styles.ts`의 후루혼야 prompt와 새 예시를 읽어 확인했다. 짧은 발성을 허용하고 자료가 적은 잠정 해석으로 명시하며 절대 무음 규칙은 없다. 이번 검수로 앱 코드·few-shot을 변경하지 않았다.

한국어 자료의 현재 확인 범위는 Aladin의 실제 표지 2쪽, Daewon의 소개, AniBox 페이지·프레임 관찰이다. Kyobo 본문 viewer와 한국어 번역 대사는 확인하지 못했고 AniBox 자막도 사용할 수 없었다. 음성을 듣거나 전사했다고 기록하지 않는다. 후루혼야가 절대 말하지 않는다고 단정하지 않으며 추가 발화 자료가 확보되면 현재의 보수적 정책을 재검토한다.

실모델 확인 범위: 임시 평가 유료 요청 2건은 모두 error 행이며 기술적 평가 성공은 0건이다. 첫 Qwen 출력은 유실됐고 두 번째 치이카와 출력 `와아…! 응…!`만 확보했으나 Generation 감사 실패로 평가가 중단됐다. 한 개 출력의 존재는 캐릭터 말투·감정 유지·한국어 자연스러움 검증 완료를 뜻하지 않는다. 16건 파일럿·전체 240입력×2모델·사람 채점·한국어 더빙 대조는 미완료이며 공식 근거와 제품 정책의 구분을 유지한다. 원본 Git 기술 candidate 배포 승인은 이러한 품질 검수와 별개다.
