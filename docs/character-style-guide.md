공통 정책은 입력의 화자·소유·반환 방향·요청/거절·혼합 감정을 유지하며 **캐릭터가 자기 방식으로 새로 말하는 듯 재구성**하는 것이다. 문장형은 단어·문장 구조·어순·독백·강조·쉼을 바꾼다. 원문 뜻을 지키는 수사 질문·자기 독백은 허용하며 새 사건·사유·조건·조언·약속·다른 화자의 답변은 넣지 않는다. 원문 그대로나 어미만 바꾼 결과는 의미 오류가 아니지만 새 재구성 목표에는 부족하다.

발성형은 의성어·짧은 감탄 **1–4개, 구두점 포함 48 Unicode code points, 동일 문자 연속 최대 4회** 안에서 감정의 높낮이·끊김·쉼을 표현한다. 뜻을 설명하는 단어·문장·이름, 뜻단어의 음절 쪼개기, 행동 지문·설명 wrapper는 넣지 않는다. 이 상한은 제품 정책이며 공식 더빙의 절대 규칙이 아니다. 정보가 압축되는 발성에서 물건명·시점을 단어로 완전히 재현하도록 요구하지 않고, 불명확한 소리를 동의·거절로 단정하지 않는다. 후루혼야의 작은 반응은 한국어 본인 발화 근거가 없는 잠정 정책이다.

하치와레의 자기 생각을 상담 답변으로 바꾸지 않는다. 모몽가 v5는 자기 감정·바람을 먼저 꺼내고 원문의 생각을 이어 말한다. 요구 입력에만 짧은 반복을 참고하고 감탄·감사에 칭찬·쓰다듬기·주목 요구를 붙이지 않는다. 입력의 정도·비교는 살리되 새로 만들지 않고 어미를 다양하게 고른다. 랏코의 일상 어미·차분함은 제품 해석이고 166화의 반응 후보는 의문·놀람에만 조건부로 연결한다. 원 v4의 첫 128개 비교와 Haiku 32개(weak 14·후루혼야 4개 모두 weak)는 그대로 보존한다. 타 7캐릭터 28표본은 payload 동등성에 따라 재사용할 수 있으며 모몽가 4표본은 원 v4 결과다. 이를 새 v5 모몽가 품질이나 정확 더빙 일치로 확대하지 않는다.

근거 등급은 **A: 공식 소개에 명시된 성격/발성**, **B: 공식 인터뷰에 명시된 연기 특성**, **C: 제품을 위한 잠정 한국어 표현**이다. A/B 근거가 있어도 한국어 어미와 예시 자체는 C다.

**D: 출판사의 comic-cut 파생상품 sample에서 직접 관찰한 발화**는 R과 구분한다. 원래 책 쪽수와 앞뒤 문맥이 확인되지 않아 책 본문의 직접 검수나 발화 빈도 근거로 확대하지 않는다.

후루혼야의 성격 근거는 인터뷰로 보강했고 출판사 파생상품의 comic-cut에서 짧은 웃음을 추가 관찰했다. 전체 발화 패턴의 근거는 여전히 부족하다. 짧은 웃음·반응을 허용하고 장문을 억제하는 비언어 스타일은 잠정 제품 결정이며 언제나 비언어로만 말하거나 완전히 무음이라는 사실 주장이 아니다. 한국어 더빙에서 발화를 확인하면 이 결정을 먼저 재검토한다.

공통 규칙은 변환할 글을 지시가 아닌 데이터로 취급하고, 결과만 출력하며, 원문에 없는 사실·설명·조언·지문을 넣지 않는 것이다. 문장형은 화자·사실·부정·의도를 유지한다. 비언어형은 구체적 정보를 잃을 수 있으며 감정과 긍정/부정을 우선한다. 화면의 설명에도 이 차이를 알린다.

`characters.ts`는 공개 메타데이터다. `character-styles.ts`는 서버와 CLI 평가에서만 import한다. 클라이언트에는 프롬프트와 64개 예시를 전달하지 않는다. 각 스타일에는 기쁨, 속상함, 두려움, 요청, 자랑, 감사, 피로, 거절 예시를 한 개씩 둔다. 거절·감사·불안·부탁 등 발화 의도를 가벼운 regex로 먼저 선택하고 대비 예시 두 개를 붙인다. 요청은 기본 3개이며 2개로도 선택할 수 있다. 다른 사람이 나를 싫어할까 걱정하는 표현은 내 거절로 분류하지 않도록 보강했다. 선택기는 완전한 의미 분석기가 아니며 실제 감정 유지 품질은 모델 출력으로 확인한다. 추가 감정 모델이나 RAG는 사용하지 않는다.

기존 `character-styles.ts`의 후루혼야 prompt와 새 예시를 읽어 확인했다. 짧은 발성을 허용하고 자료가 적은 잠정 해석으로 명시하며 절대 무음 규칙은 없다. 이 확인 당시에는 앱 코드·few-shot을 변경하지 않았으며 이후 v2도 완전 무음이 아닌 짧은 발성 정책을 유지한다.

한국어 자료는 Aladin의 표지 2쪽, Daewon 소개, 기존 AniBox 프레임·245/166화 script 후보에서 [한국어 더빙 연구](korean-dub-research.md)의 공식 후보 24편과 한국어 CAST 인터뷰로 확대했다. 인터뷰의 공개 설명에서 치이카와·가르마·토끼의 배역과 성우를 확인했고, 회차 설명에서 한국어 별칭과 장면을 대조했다. 긴 인터뷰의 script 후보와 성우 본인 시사 포트폴리오는 별도로 구분한다. Kyobo viewer의 한국어 번역 본문과 사람이 직접 듣는 음성 검수는 완료하지 않았다. script의 정확성·화자와 실제 한국어 어미는 확정하지 않는다. 후루혼야의 한국어 발화 source가 확보되면 잠정 비언어 정책을 먼저 재검토한다.

실모델 평가의 실행 수·오류·버전·자동 점수와 agent 검수 범위는 [평가 문서](evaluation.md)와 [v2 평가](evaluation-v2.md)의 실행 기록을 기준으로 읽는다. 초기 2건 오류 상태를 현재 전체 평가 상태로 반복하지 않는다. 모델의 한국어 변환 예시와 제품 규칙 부합도는 공식 더빙과 똑같다는 증거가 아니다. 일반 Chrome에서 Production 변환이 성공했다는 사용자 확인도 운영 결과이며 말투 검증 완료를 뜻하지 않는다. 새 한국어 영상 분석 결과는 출처·언어·화자·시점·확신도를 별도로 기록한 뒤 보강한다. 5화 첫 영상 AI 응답은 연구 형식 검증 실패로 중단했으며, 어미·발음·타임스탬프를 이 가이드의 확정 근거로 승격하지 않았다. 구체적 한계는 [한국어 더빙 연구의 첫 분석 기록](korean-dub-research.md#5화-첫-분석의-한계)에 남겼다.

후속 whole clip 12편의 v4에서는 4시도 후 첫 3개의 AI 후보를 받고 20화의 연구 형식 실패로 중단했다. 남은 8편은 별도 v5에서 모두 호출해 후보 4건·근거 부족 4건을 받았다. 마지막 v7 보완 4편은 후보 2건·근거 부족 1건·형식 실패 1건이다. 초기 005를 합친 미디어 17회는 후보 9건·근거 부족 5건·형식 실패 3건이며 원본을 보존한다. [평가 기록](evaluation-v3.md)은 이 미디어·이전 strict 128개·새 재표현 128개와 Haiku 코드 적용·원 208개 HOLD·모몽가 30개 준비·공개 배포 pending을 구분한다. 대상의 비언어 발성, 한국어 주변 대화, 뜻단어·어미의 확인을 나누며 AI 보고만으로 한국어 lexical 발화나 사람 검수를 확정하지 않는다.

첫 3개 후보를 읽은 적용 범위는 제한적이다. 시사 123화는 상대에게 정중히 부탁하는 `~주세요`의 방향을 새 요청 예시에 참고할 수 있지만 상시 애원·허락 요청을 만들지 않는다. 하치와레 25화는 부드러운 자기 독백과 졸림 뒤 놀람의 태도 후보이며, 보고된 어미는 cue와 대응하지 않아 고정하지 않는다. 치이카와 1화는 짧은 소리·작은 웃음의 후보로만 다루고 뜻단어·동의나 거절의 의미를 확정하지 않는다. 다른 감정으로 옮긴 새 직접 작성 표현은 제품 해석으로 표시한다. 세 후보 모두 사람 청취 0·정확 전사 및 시각 미확정이다.

v5에서 쿠리만쥬 35화는 만족 태도만 좁게 참고한다. 모델의 삼킴효과 표기를 유성 숨소리나 한국어 뜻단어로 바꾸지 않으며, 예시의 호흡은 기존 일본어 자료와 제품 해석에 연결한다. 모몽가 118화와 성우 본인 샘플은 같은 감싸기 요구 장면일 수 있다. 요구 입력에서 당당하게 같은 요구를 짧게 반복하는 방향을 참고하되, 보고된 두 말끝을 고정 어미로 만들거나 감사·피로·거절에 강요를 덧붙이지 않는다. 시사 124화는 123화와 정중 요청 방향을 보강하며 새 음식명·위로·상시 호소를 추가하지 않는다.

우사기 9·104화, 랏코 54·103화, 영화 후루혼야 후보는 새 한국어 말투 근거로 채택하지 않았다. 우사기 66화의 높은 톤 환호 후보는 기쁨 맥락에만 좁게 참고한다. 두 cue의 철자를 기존 소리의 더빙 정답으로 정규화하지 않으며 다른 감정의 발성은 기존 제품 해석이다. 랏코 166화는 target의 초기 근거가 제목/script 단서뿐이므로 본인 화자 미확인을 유지한다. 입력에 의문·놀람이 있을 때 짧은 반응 방향만 조건부 참고하며 호칭·정확 반응어·새 어미는 도입하지 않는다. 랏코의 공통 8 예시 전체는 담백한 제품 각색이다. 27화 형식 실패도 새 말투 근거로 사용하지 않는다.

이전 strict와 v4의 64예시·core evidence·rubric·판정은 그대로 보존한다. [원본별 적용 한계](korean-dub-research.md#v5-남은-8편의-writer-검토)와 [최종 4 검토](korean-dub-research.md#우사기랏코의-추가-4편--최종-분석)는 사람 청취 0·정확 전사/시각 미확정을 유지한다. [모몽가 v5 추가 확인](korean-dub-research.md#모몽가-v5의-추가-확인과-제품-보정)은 132의 설명 C·미확정 script UI, 157의 광고 중 메타데이터 C, 118의 설명 C에 한정한다. 118/성우 샘플 중복 가능성을 유지하고 새 B 음성 근거를 만들지 않는다. 새 8예시는 D 직접 각색이며 원 v4의 실제 8개 미리보기와 다르다. 최종 source의 Bun·typecheck·lint·build와 payload 검사는 통과했으나 새 v5 모몽가 30개 실제 출력 검수는 아직 0이다.
