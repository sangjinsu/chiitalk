# 캐릭터 말투와 근거

확인일: 2026-10-10. 공식 애니메이션 소개와 성우 인터뷰를 직접 읽었다. 예시 64개는 새로 쓴 한국어 재해석이며 공식 대사 인용이 아니다. 원작 만화 컷의 실제 발화와 한국어 더빙 음성을 직접 대조하지 않았으므로, 한국어 표기·말끝·소리의 길이가 공식 더빙과 같다고 주장하지 않는다.

근거 등급은 **A: 공식 소개에 명시된 성격/발성**, **B: 공식 인터뷰에 명시된 연기 특성**, **C: 제품을 위한 잠정 한국어 표현**이다. A/B 근거가 있어도 한국어 어미와 예시 자체는 C다.

| ID / 표시명 | 공식 근거와 해석 | 출력 규칙 | 피할 표현 |
|---|---|---|---|
| chiikawa / 치이카와 | A: 조금 울보이고 상냥함 | 1~3개 작은 소리; 기쁨·두려움·거절 구별 | 유창한 문장, 모든 감정을 울음으로 처리 |
| hachiware / 하치와레 | A: 밝고 긍정적 | 짧고 솔직한 다정한 반말 | 냥/야옹, 원문에 없는 해결책 |
| usagi / 우사기 | A: 우라/야하 같은 큰 외침 | 1~3개 외침, 높이·길이·쉼으로 감정 구별 | 긴 문장, 행동 지문 |
| kurimanju / 쿠리만쥬 | A: 미식과 돌봄; B: 대사는 단어가 아닌 호흡의 뉘앙스 | 1~3개 숨·감탄 | 어른 사투리, 입력에 없는 술/음식 |
| momonga / 모몽가 | A: 귀여운 척하며 조름 | 요구 맥락의 당당한 짧은 반말 | 상시 무례함, 모욕·협박 |
| rakko / 랏코 | A: 강하고 동경의 대상; B: 강함과 사랑스러움 | 차분하고 단정한 말투 | 상시 군대 말투·전투 비유 |
| shisa / 시사 | B: 꾸준히 노력, 말끝을 늘임 | 짧은 존댓말, 맥락에 맞는 ~ 한 번 | 한국 지역 사투리, 상시 스승 호칭 |
| furuhonya / 후루혼야 | A: 헌책 판매; B: 배려·솔직함·용기 | 자료 부족으로 작은 발성에 한정한 C 해석 | 검증 없는 고유 어미·서점 설정 첨가 |

후루혼야의 성격 근거는 인터뷰로 보강했지만 발화 패턴의 근거는 여전히 부족하다. 비언어 스타일은 보수적인 제품 결정이며 공식 캐릭터가 언제나 비언어로만 말한다는 사실 주장이 아니다. 한국어 더빙에서 발화를 확인하면 이 결정을 먼저 재검토한다.

공통 규칙은 변환할 글을 지시가 아닌 데이터로 취급하고, 결과만 출력하며, 원문에 없는 사실·설명·조언·지문을 넣지 않는 것이다. 문장형은 화자·사실·부정·의도를 유지한다. 비언어형은 구체적 정보를 잃을 수 있으며 감정과 긍정/부정을 우선한다. 화면의 설명에도 이 차이를 알린다.

`characters.ts`는 공개 메타데이터다. `character-styles.ts`는 서버와 CLI 평가에서만 import한다. 클라이언트에는 프롬프트와 64개 예시를 전달하지 않는다. 각 스타일에는 기쁨, 속상함, 두려움, 요청, 자랑, 감사, 피로, 거절 예시를 한 개씩 둔다. 감정 regex로 첫 번째 관련 예시와 두 개의 대비 예시를 결정적으로 선택한다. 추가 감정 모델이나 RAG는 사용하지 않는다.

- [한국 AniBox 시사 등장편](https://www.youtube.com/watch?v=2QMuuqfdZJY): 이전 조사에서 확인한 대조 후보. 이번 구현에서 음성·자막 전사를 확인하지 못했다.

다음 출시 검증에서는 공식 원작 발화 컷 및 AniBox 더빙의 실제 발화 시점·어미를 소량 대조한다. 캐릭터당 다른 감정의 짧은 샘플을 확인하고, 출처 시점과 관찰 내용을 기록한다. 공개 평가 데이터에는 공식 대사의 대량 복제를 넣지 않는다.

하치와레의 특정 음식 이름 말실수는 해당 장면에 관한 근거이며, 모든 입력에 말실수를 넣는 고정 규칙으로 삼지 않는다. 후루혼야의 짧은 비언어 출력은 기존의 보수적인 provisional 제품 정책을 유지한다. 공식 자료로 확정한 절대 규칙이나 한국어 더빙 말버릇으로 취급하지 않는다. 원작 컷·한국어 더빙 실제 발화 대조는 여전히 남아 있다.
