| 표기 | 실제 확인한 것 | 확정할 수 없는 것 |

| ending / short word | 들리는 어미, 작은 뜻단어, 발성·웃음·숨의 구분, 해당 시점 | 애매한 모음·호흡을 임의의 단어로 전사하지 않음; 단어 금지 정책을 먼저 정답으로 가정하지 않음 |
| attitude / volume | 감정, 상대를 대하는 태도, 발화량, 소리 강약의 상대 차이 | 높은 에너지를 모든 장면의 고함으로, 정중함을 모든 장면의 늘임표로 만들지 않음 |
| uncertainty | 언어·화자·전사·리듬 각각의 모델 확신도와 미확정 이유 | 모델의 높은 자체 확신도를 수동 청취나 정확도 보증으로 표시하지 않음 |

실제 소리가 불분명한 구간은 읽을 수 있는 정확한 대사처럼 공표하지 않는다. 공개 기록에는 필요한 짧은 표기와 특징 요약만 남기고, 원문 대사의 전문이나 장면 전체 대화는 예시 데이터로 복제하지 않는다.

API 응답이나 비용 감사가 성공해도 영상·음성 접근이 확인되지 않는 답변, 제목만 되풀이한 답변, 의미 있는 발화 근거가 없는 답변은 실제 음성 검수 성공으로 세지 않는다. 언어 또는 화자 대응을 분석하지 못했다는 응답은 그 한계를 보존하고 해당 규칙을 잠정 상태로 둔다.

공식 출처와 15초 전체 길이는 확인했지만 이번 v5 분석은 한국어 본인 발화 근거를 남기지 못했다. 후속 자료를 `AI-observed` 발화 후보로 쓰려면 실제 오디오의 언어, 입 움직임이나 대화 반응과 본인 음성의 대응, 내레이터·다른 인물·가창의 구별, 전사·화자·특징의 불확실성이 함께 기록되어야 한다. 시작·끝 시각이 제공되면 단위와 구간을 검증하고, whole clip 관찰만 있으면 정확 시각을 주장하지 않는다. 설명 음성만 있거나 대응이 모호하면 캐릭터 소개 자료로 유지한다.

한 영화 홍보의 한 소리가 확인되어도 영화의 그 장면에 관한 근거다. TV 한국어 어미나 작품 전체의 말버릇 빈도로 확대하지 않는다. 작은 뜻단어가 명확히 확인되면 현재의 단어 절대 금지 제품 정책을 재검토할 수 있지만, 한 번의 모호한 AI 전사만으로 유창한 문장형을 도입하지 않는다. `AI-observed`는 사람 청취 0과 함께 표시하며 공식 검수 자막과 구분한다.

## 재표현 제품 정책과 근거의 분리

사용자는 뜻·감정을 지키면서 캐릭터가 자기 방식으로 새로 말하는 듯 표현하기를 원한다. 원 v4 비교에 쓴 `2026-10-11-v4-reexpress` source와 직접 작성 64개 예시는 제품 해석의 동결 snapshot이다. 당시 style SHA는 `dc38a9de4e3a8fd11e2dbff34d0ccc9c0b1132da976695a71b47a6c54fde4163`, 예시 SHA는 `aac6644ef6888a6897539179503c8432dc253604bb9cbd3a11d840ccf58b0380`이다. 이후 최종 v5는 모몽가만 별도 보정했다. 새 source를 추가 공식 음성 근거로 세지 않으며 원 미디어 17개·제한 후보 9개·사람 청취 0·후루혼야 본인 한국어 발화 0은 그대로다.

문장 구조·어순·자기 독백·수사 질문·강조·리듬과 발성의 감정 흐름은 제품 표현 축 D로 평가한다. 뜻·역할·반환 방향·부정/거절·핵심 감정을 뒤집거나 새 사실·사유·조건·약속·조언을 추가하는 의미 오류와 분리한다. 공식 후보 B는 앞 표의 좁은 장면 범위에만 연결하고, 정확 어미·음절·감정별 대응·작품 전체 발화 규칙으로 확대하지 않는다. 모몽가 중복 가능성, 쿠리만쥬 삼킴효과, 랏코 조건부 화자, 우사기 환호의 철자 미확정도 유지한다.
